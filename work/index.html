LFI Simulator

Open Source Directory Traversal Filesystem Hardening

Problem: Template loaders and static file endpoints often trust user-supplied filenames or rely on brittle regex replacements that crumble under percent-encoding or root-anchored paths.

Engineering: Created an educational Local File Inclusion simulator showing how traversal sequences resolve on POSIX paths—and how canonicalizing paths with realpath plus strict root-prefix checks stops jailbreaks before disk access.
